# Math practice

Small browser-based math exercises for kids. No build step, no dependencies — plain static HTML.

## Exercises

- **[Number families](https://bmateusz.github.io/math-practice/number-families.html)** — addition and subtraction fact families, with optional crossing-ten problems. Available in English, Hungarian and German.

## Run locally

Open `number-families.html` in a browser, or serve the folder:

```sh
python3 -m http.server
```

## Deployment

Published with GitHub Pages from the `main` branch root: https://bmateusz.github.io/math-practice/
